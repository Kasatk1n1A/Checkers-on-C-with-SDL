# Функции
## IMG_GetError()
**IMG_GetError()** — это функция из библиотеки SDL_image, которая используется для получения текстового описания последней ошибки, возникшей при работе с функциями этой библиотеки. Она помогает разработчикам диагностировать и устранять проблемы, связанные с загрузкой и обработкой изображений.

Функция IMG_GetError не принимает параметров и возвращает строку с описанием ошибки. Если ошибок не было, функция возвращает пустую строку.

Эта функция часто используется в сочетании с другими функциями SDL_image, такими как IMG_Init или IMG_LoadTexture, для обработки ошибок и предоставления пользователю более подробной информации о возникших проблемах.

## IMG_Init()
**IMG_Init()** — это функция из библиотеки SDL_image, расширения для SDL (Simple DirectMedia Layer). Она инициализирует подсистемы загрузки изображений, которые позволяют работать с различными форматами файлов, такими как PNG, JPG, GIF и другими.
### Синтаксис[![](https://wiki.libsdl.org/static_files/link.svg)](https://wiki.libsdl.org/SDL2_image/IMG_Init#syntax)

```
int IMG_Init(int flags);
```
Функция IMG_Init принимает один параметр — флаг, который представляет собой битовую маску и указывает, какие подсистемы загрузки изображений нужно инициализировать. Возможные флаги:

- IMG_INIT_PNG — для поддержки формата PNG;
- IMG_INIT_JPG — для поддержки формата JPG;
- IMG_INIT_GIF — для поддержки формата GIF и так далее.

При успешном выполнении функция IMG_Init возвращает битовую маску, указывающую, какие подсистемы были успешно инициализированы. В случае ошибки возвращается 0, и можно использовать функцию IMG_GetError для получения дополнительной информации об ошибке.

Перед использованием функций SDL_image, таких как IMG_LoadTexture, необходимо вызвать IMG_Init для инициализации соответствующих подсистем загрузки изображений. Это позволяет обеспечить корректную работу с изображениями в приложении.
## IMG_LoadTexture()
**IMG_LoadTexture()** — это функция из библиотеки SDL_image, расширения для SDL (Simple DirectMedia Layer), которая позволяет загружать изображения в формате SDL_Texture. Она упрощает процесс загрузки изображений из файлов и их подготовки к рендерингу в приложениях SDL.

### Синтаксис[![](https://wiki.libsdl.org/static_files/link.svg)](https://wiki.libsdl.org/SDL2_image/IMG_LoadTexture#syntax)

```
SDL_Texture * IMG_LoadTexture(SDL_Renderer *renderer, const char *file);
```

Функция IMG_LoadTexture() принимает два параметра:

1. **renderer** — объект рендера (SDL_Renderer), который будет использоваться для создания текстуры.
2. **file** — путь к файлу изображения, который нужно загрузить.

При успешном выполнении функция возвращает указатель на созданную текстуру (SDL_Texture), которую можно использовать для рендеринга на экране. В случае ошибки возвращается NULL, и можно использовать функцию IMG_GetError для получения дополнительной информации об ошибке.

Использование IMG_LoadTexture упрощает процесс загрузки и отображения изображений в приложениях SDL, поскольку она автоматически обрабатывает все необходимые шаги, включая создание текстуры и освобождение ресурсов. Это делает её удобным инструментом для разработчиков, работающих с графикой в SDL.

### Замечания[![](https://wiki.libsdl.org/static_files/link.svg)](https://wiki.libsdl.org/SDL2_image/IMG_LoadTexture#remarks)

SDL_Texture представляет собой изображение в памяти графического процессора, которое можно использовать с помощью API 2D-рендеринга SDL. Это может быть значительно эффективнее, чем использование SDL_Surface, привязанного к процессору, если вам не нужно управлять изображением сразу после его загрузки.

Если загруженное изображение имеет прозрачность или цветовую палитру, будет создана текстура с альфа-каналом. В противном случае SDL_image попытается создать SDL_Texture в наиболее подходящем формате для представления данных изображения (но во многих случаях это будет просто 32-битный RGB или 32-битный RGBA).

Существует отдельная функция для чтения файлов из SDL_RWops, если вам нужна абстракция ввода-вывода для получения данных откуда угодно вместо простого чтения из файловой системы. Эта функция называется [IMG_LoadTexture_RW](https://wiki.libsdl.org/SDL2_image/IMG_LoadTexture_RW)().

Если вы предпочитаете декодировать изображение в SDL_Surface (буфер пикселей в памяти процессора), вызовите [IMG_Load](https://wiki.libsdl.org/SDL2_image/IMG_Load)() вместо этого.

Когда приложение закончит работу с возвращённой текстурой, оно должно удалить её с помощью вызова SDL_DestroyTexture().

## IMG_Quit()
**IMG_Quit()** — это функция из библиотеки SDL_image, которая используется для освобождения ресурсов и завершения работы с подсистемами загрузки изображений, инициализированными ранее с помощью функции IMG_Init. Она необходима для корректного завершения работы с библиотекой SDL_image перед выходом из приложения.

Функция IMG_Quit не принимает параметров и не возвращает значения. Её вызов гарантирует, что все выделенные ресурсы, связанные с подсистемами загрузки изображений, будут корректно освобождены, что помогает избежать утечек памяти и других проблем.
